# Screenshot checklist

Capture the **running application**, then save the original screenshots here. Suggested filenames:

- `login.png` — welcome and login screen.
- `inventory.png` — customer inventory, search filters, and stock availability.
- `admin.png` — admin inventory and vehicle controls.

Remove or hide personal information. Do not include passwords, token values, or browser developer tools containing secrets. Update the root README with Markdown image links once the files exist. This folder intentionally contains no invented screenshots.
